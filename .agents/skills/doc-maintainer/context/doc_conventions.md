# Documentation Conventions

- **Architecture Decision Records**: Stored in `docs/adr/NNNN-title.md`.
- **API Specs & Guides**: Stored in `docs/api/`.
- **Primary README**: Keep high-level overview, architecture diagrams, and quickstart instructions up-to-date with code changes.
- **Rules**:
  - Always verify markdown links work.
  - Keep mermaid diagrams minimal and readable.
  - Never include AI watermarks or AI-generated disclaimers in docs.
