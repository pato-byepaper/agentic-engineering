# Plan Conventions & Storage

- **Directory**: `plans/` at the root of the project.
- **Naming Pattern**: `YYYYMMDD-<type>-<name>.md`
  - Examples:
    - `plans/20261024-feature-user-notifications.md`
    - `plans/20261024-bugfix-cart-quantity-discount.md`
    - `plans/20261024-refactor-auth-service-modularization.md`
    - `plans/20261024-performance-checkout-lcp-optimization.md`
- **Lifecycle**: Draft -> Approved by Tech Lead / User -> In Progress -> Completed.
