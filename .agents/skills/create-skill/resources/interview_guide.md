# Skill Discovery & Pain Point Interview Guide

Use these questions when helping a developer translate an operational pain point into a reusable Antigravity skill:

---

## 1. Problem Identification
- "What manual task or repetitive workflow are we trying to automate?"
- "What makes this task prone to errors or tedious when developers do it manually?"

## 2. Technical Procedure
- "Can you list the exact steps, terminal commands, or API calls you make today?"
- "Which files or directory trees are modified during this process?"

## 3. Trigger & Context
- "When should an agent automatically decide to activate this skill?"
- "What keywords, user intents, or error patterns should trigger it?"

## 4. Verification & Output
- "What command output or test confirms that this task was executed properly?"
- "What is the expected final artifact (e.g. a commit, PR, report, migration, build artifact)?"

## 5. Failure Modes & Edge Cases
- "What are the common gotchas, traps, or failure states?"
- "What should the agent do if a step fails or dependencies are missing?"
