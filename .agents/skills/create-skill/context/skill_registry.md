# Skill Registry & Guidelines

List of custom skills in this repository:

- `manager`: Product vision, UX flows, ticket acceptance.
- `tech-lead`: Architecture, interface contracts, stacked PR planning.
- `data-engineer`: Schema reviews, migrations, RLS, query performance.
- `backend-developer`: Domain models, API endpoints, validations, server tests.
- `frontend-developer`: Client UI, responsiveness, Google Core Web Vitals.
- `tester`: Independent verification in `test-results/<issue>.md`.
- `git-publisher`: Conventional commits, single and stacked PRs, zero AI tags.
- `setup`: Automated repository scanning and agent context population.
- `create-skill`: Converts developer pain points and procedures into modular skills.
- `coder`: Single-issue triage and implementation.
